# [OPEN] text-resize-not-working

## 现象
- 文本模式下，右下角缩放手柄无法正常缩放文本节点。

## 预期
- 拖动缩放手柄后，文本字号和文本框尺寸同步变化。

## 当前假设
1. 缩放手柄没有成功进入 `resize` 交互分支。
2. `font-size` 被改了，但当前文本显示不受这个属性控制。
3. `getBBox()` 没有在缩放后正确刷新，导致框看起来没变化。
4. 缩放手柄事件被覆盖层拦截，根本没有开始缩放。

## 计划
- 先检查缩放分支和文本节点的 `font-size` / `tspan` 结构。
- 在不引入调试服务器的前提下做最小修复。
